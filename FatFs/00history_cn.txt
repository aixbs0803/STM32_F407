----------------------------------------------------------------------------
  FatFs 模块版本历史
----------------------------------------------------------------------------

R0.00 (2006年2月26日)

  原型版本。


R0.01 (2006年4月29日)

  首次发布。


R0.02 (2006年6月1日)

  添加 FAT12 支持。
  移除无缓冲模式。
  修复小分区(<32M)的问题。


R0.02a (2006年6月10日)

  添加配置选项 _FS_MINIMUM。


R0.03 (2006年9月22日)

  添加 f_rename()。
  将选项 _FS_MINIMUM 改为 _FS_MINIMIZE。


R0.03a (2006年12月11日)

  改进簇扫描算法以加快文件写入速度。
  修复 f_mkdir() 在 FAT32 上创建不正确目录的问题。


R0.04 (2007年2月4日)

  添加 f_mkfs()。
  支持多驱动器系统。
  为多驱动器系统更改了一些接口。
  将 f_mountdrv() 改为 f_mount()。


R0.04a (2007年4月1日)

  支持物理驱动器上的多个分区。
  为 f_lseek() 添加扩展文件大小的功能。
  添加最小化级别 3。
  修复 f_mkfs() 中的字节序敏感代码。


R0.04b (2007年5月5日)

  添加配置选项 _USE_NTFLAG。
  添加 FSINFO 支持。
  修复 DBCS 名称可能导致 FR_INVALID_NAME 的问题。
  修复短寻道(<= csize)会破坏文件对象的问题。


R0.05 (2007年8月25日)

  更改 f_read()、f_write() 和 f_mkfs() 的参数。
  修复 f_mkfs() 在 FAT32 上创建不正确 FSINFO 的问题。
  修复 f_mkdir() 在 FAT32 上创建不正确目录的问题。


R0.05a (2008年2月3日)

  添加 f_truncate() 和 f_utime()。
  修复 FAT 子类型确定时的 off-by-one 错误。
  修复 f_read() 中的 btr 可能被错误截断的问题。
  修复创建并关闭文件但不写入时缓存扇区未刷新的问题。


R0.06 (2008年4月1日)

  添加 fputc()、fputs()、fprintf() 和 fgets()。
  改进 f_lseek() 在移动到相同或后续簇时的性能。


R0.07 (2009年4月1日)

  合并 Tiny-FatFs 作为配置选项。(_FS_TINY)
  添加长文件名功能。(_USE_LFN)
  添加多代码页功能。(_CODE_PAGE)
  添加多任务操作的可重入性。(_FS_REENTRANT)
  为 f_mkfs() 添加自动簇大小选择。
  为 f_readdir() 添加回卷选项。
  更改严重错误的返回代码。
  重命名字符串函数以避免名称冲突。


R0.07a (2009年4月14日)

  将可重入配置中的 OS 相关代码分离出来。
  添加多扇区大小功能。


R0.07c (2009年6月21日)

  修复 f_unlink() 在错误时可能返回 FR_OK 的问题。
  修复 f_lseek() 中的错误缓存控制。
  添加相对路径功能。
  添加 f_chdir() 和 f_chdrive()。
  为扩展字符添加正确的大小写转换。


R0.07e (2009年11月3日)

  将配置选项从 ff.h 分离到 ffconf.h。
  修复 f_unlink() 在 _FS_RPATH 模式下无法删除子目录的问题。
  修复第13个字符边界上的名称匹配错误。
  添加配置选项 _LFN_UNICODE。
  更改 f_readdir() 在非 LFN 配置下始终返回大写 SFN。


R0.08 (2010年5月15日)

  添加内存配置选项。(_USE_LFN = 3)
  添加文件锁功能。(_FS_SHARE)
  添加快速寻道功能。(_USE_FASTSEEK)
  更改 API 中的一些类型，XCHAR->TCHAR。
  更改 Unicode 配置下 FILINFO 结构中的 .fname。
  字符串函数在 Unicode 配置下支持 UTF-8 编码文件。


R0.08a (2010年8月16日)

  添加 f_getcwd()。(_FS_RPATH = 2)
  添加扇区擦除功能。(_USE_ERASE)
  将文件锁信号量表从 fs 对象移动到 bss。
  修复 f_mkfs() 创建错误 FAT32 卷的问题。


R0.08b (2011年1月15日)

  快速寻道功能也应用于 f_read() 和 f_write()。
  f_lseek() 在创建 CLMP 时报告所需的表大小。
  扩展 f_printf() 的格式语法。
  忽略给定路径名中的重复目录分隔符。


R0.09 (2011年9月6日)

  f_mkfs() 支持多个分区以完成多分区功能。
  添加 f_fdisk()。


R0.09a (2012年8月27日)

  更改 f_open() 和 f_opendir() 拒绝空对象指针以避免崩溃。
  将选项名 _FS_SHARE 改为 _FS_LOCK。
  修复 FAT12/16 卷上 OS/2 EA 导致的断言失败。


R0.09b (2013年1月24日)

  添加 f_setlabel() 和 f_getlabel()。


R0.10 (2013年10月2日)

  添加文件字符编码选择。(_STRF_ENCODE)
  添加 f_closedir()。
  为 f_getfree() 添加强制完整 FAT 扫描。(_FS_NOFSINFO)
  通过更改 f_mount() 添加强制挂载功能。
  改进卷自动检测行为。
  改进 f_puts() 和 f_printf() 的写入吞吐量。
  更改 f_chdrive()、f_mkfs()、disk_read() 和 disk_write() 的参数。
  修复文件大小接近 4GB 时 f_write() 可能被截断的问题。
  修复 f_open()、f_mkdir() 和 f_setlabel() 在错误时可能返回不正确值的问题。


R0.10a (2014年1月15日)

  添加路径名中的任意字符串作为驱动器号。(_STR_VOLUME_ID)
  添加最小扇区大小的配置选项。(_MIN_SS)
  f_rename() 的第二个参数可以有驱动器号，将被忽略。
  修复驱动器号 >= 1 时强制挂载失败的问题。(出现在 R0.10)
  修复 f_close() 未锁定卷时使文件对象无效的问题。
  修复 f_closedir() 返回但卷锁仍保持获取状态的问题。(出现在 R0.10)
  修复 LFN 创建条目在 SFN 冲突过多时失败的问题。(出现在 R0.07)


R0.10b (2014年5月19日)

  修复磁盘 I/O 层的严重错误可能破坏目录条目的问题。
  修复删除/重命名具有有损转换 SFN 的对象时 LFN 条目未被删除的问题。(出现在 R0.07)


R0.10c (2014年11月9日)

  添加无 RTC 平台的配置选项。(_FS_NORTC)
  将选项名 _USE_ERASE 改为 _USE_TRIM。
  修复 Mac OS X 创建的卷标无法通过 f_getlabel() 获取的问题。(出现在 R0.09b)
  修复 FAT 访问中磁盘错误时可能出现的潜在问题。
  修复尝试删除根目录时的空指针解引用问题。(出现在 R0.08)


R0.11 (2015年2月9日)

  添加 f_findfirst()、f_findnext() 和 f_findclose()。(_USE_FIND)
  修复 f_unlink() 不删除文件簇链的问题。(出现在 R0.10c)
  修复 _FS_NORTC 选项无法正常工作的问题。(出现在 R0.10c)


R0.11a (2015年9月5日)

  修复错误的介质更改可能导致线程安全配置死锁的问题。
  添加代码页 771、860、861、863、864、865 和 869。(_CODE_PAGE)
  移除标准系统上实际上不存在的一些代码页。(_CODE_PAGE)
  修复代码页 437 和 850 的大小写转换表错误(ff.c)。
  修复 Unicode 的大小写转换表错误(cc*.c)。


R0.12 (2016年4月12日)

  添加 exFAT 文件系统支持。(_FS_EXFAT)
  添加 f_expand()。(_USE_EXPAND)
  更改 FINFO 结构中的一些成员和 f_readdir() 的行为。
  添加选项 _USE_CHMOD。
  移除选项 _WORD_ACCESS。
  修复 Unicode 的大小写转换表错误(cc*.c)。


R0.12a (2016年7月10日)

  通过修改 f_mkfs() 添加创建 exFAT 卷的支持。
  添加文件打开方法 FA_OPEN_APPEND。不再需要在 f_open() 之后调用 f_lseek()。
  f_forward() 无论 _FS_TINY 如何都可用。
  修复 f_mkfs() 创建错误卷的问题。(出现在 R0.12)
  修复 create_name() 中的错误内存读取问题。(出现在 R0.12)
  修复某些配置下编译失败的问题，_USE_FASTSEEK 和 _USE_FORWARD。


R0.12b (2016年9月4日)

  使 f_rename() 能够重命名名称相同但大小写不同的对象。
  修复代码页 866 的大小写转换表错误。(ff.c)
  修复 exFAT 卷上文件偏移量 4GiB 处写入数据被截断的问题。(出现在 R0.12)
  修复在 exFAT 卷根目录创建文件可能失败的问题。(出现在 R0.12)
  修复 f_mkfs() 创建簇大小过小的 exFAT 卷可能破坏未分配内存的问题。(出现在 R0.12)
  修复 Unicode 配置下读取目录时可能返回错误对象名称的问题。(出现在 R0.12)
  修复 exFAT 卷上大文件分配/删除破坏分配位图的问题。(出现在 R0.12)
  修复 f_expand() 和 f_lseek() 中的一些内部错误。(出现在 R0.12)


R0.12c (2017年3月4日)

  改进 exFAT 卷上碎片化文件的写入吞吐量。
  使 exFAT 的内存使用能够通过减小 _MAX_LFN 来减少。
  修复 FAT12/16 卷上连续调用 f_getfree() 可能返回错误计数的问题。(出现在 R0.12)
  修复配置选项 _VOLUMES 不能设置为 10 的问题。(出现在 R0.10c)


R0.13 (2017年5月21日)

  将配置关键字的首字符从 "_" 改为 "FF_"。
  移除纯 ASCII 配置，FF_CODE_PAGE = 1。改用 FF_CODE_PAGE = 437。
  添加 f_setcp()，运行时代码页配置。(FF_CODE_PAGE = 0)
  改进深层嵌套簇链扩展时的簇分配时间。
  通过使用 FF_USE_LFN = 3 改进大簇大小下 f_mkdir() 的处理时间。
  改进碎片化文件的 NoFatChain 标志在截断后变为连续时被设置。
  修复 exFAT 卷上重命名文件时存档属性未设置的问题。(出现在 R0.12)
  修复对 exFAT 卷上现有文件进行写入或 lseek 操作时 FAT 条目可能被破坏的问题。(出现在 R0.12c)
  修复 exFAT 目录发生新簇分配时创建文件可能失败的问题。(出现在 R0.12c)


R0.13a (2017年10月14日)

  添加 API 上的 UTF-8 编码支持。(FF_LFN_UNICODE = 2)
  添加文件名输出缓冲区选项。(FF_LFN_BUF, FF_SFN_BUF)
  为 f_mkfs() 和 f_fdisk() 的工作缓冲区添加动态内存分配选项。
  修复 f_fdisk() 和 f_mkfs() 创建具有错误 CHS 参数的分区表的问题。(出现在 R0.09)
  修复 exFAT 卷上碎片化文件的 f_unlink() 可能导致丢失簇的问题。(出现在 R0.12c)
  修复 f_setlabel() 拒绝 exFAT 卷的某些有效字符的问题。(出现在 R0.12)


R0.13b (2018年4月7日)

  添加 API 上的 UTF-32 编码支持。(FF_LFN_UNICODE = 3)
  添加 Unix 风格卷 ID 支持。(FF_STR_VOLUME_ID = 2)
  修复访问 exFAT 根目录上超出簇边界的任何对象可能失败的问题。(出现在 R0.12c)
  修复 f_setlabel() 不拒绝某些无效字符的问题。(出现在 R0.09b)


R0.13c (2018年10月14日)
  支持 C99 及更高版本的 stdint.h。(integer.h 已包含在 ff.h 中)
  修复最后一个目录条目不为空时读取目录进入无限循环的问题。(出现在 R0.12)
  修复在 exFAT 卷上碎片化子目录中创建子目录破坏父目录 FAT 链的问题。(出现在 R0.12)
  修复 f_getcwd() 在缓冲区包含有效驱动器号时导致输出缓冲区溢出的问题。(出现在 R0.13b)


R0.14 (2019年10月14日)
  添加 64 位 LBA 和 GUID 分区表支持(FF_LBA64 = 1)
  更改一些 API 函数，f_mkfs() 和 f_fdisk()。
  修复 f_open() 函数无法找到长度为 FF_MAX_LFN 字符的文件名的问题。
  修复 f_readdir() 函数无法检索长度为 FF_MAX_LFN - 1 字符的长文件名的问题。
  修复 f_readdir() 函数返回大小写转换错误的文件名的问题。(出现在 R0.12)
  修复 f_mkfs() 函数在第二个分区中创建 exFAT 卷可能失败的问题。(出现在 R0.12)


R0.14a (2020年12月5日)
  限制 f_findnext() 中的递归调用次数。
  修复 MS-DOS 2.x 和 3.x 格式化的旧软盘无法挂载的问题。
  修复一些编译器警告。


R0.14b (2021年4月17日)
  使 FatFs 使用标准库 <string.h> 进行复制、比较和搜索，而不是内置字符串函数。
  为 f_printf() 添加长整型和浮点型支持。(FF_STRF_LLI 和 FF_STRF_FP)
  使路径名解析器忽略终止分隔符以允许 "dir/"。
  改进 Unix 风格路径名功能的兼容性。
  修复某些条件下 f_open() 失败时文件被死锁的问题。(出现在 R0.12a)
  修复 f_mkfs() 由于时序相关错误可能创建错误 exFAT 卷的问题。(出现在 R0.12)
  修复代码页 855 无法通过 f_setcp() 设置的问题。
  修复一些编译器警告。


R0.15 (2022年11月6日)
  更改用户提供的同步函数，以完全消除 FatFs 代码中的平台依赖性。
  FF_SYNC_t 从配置选项中移除。
  修复 FF_FS_REENTRANT 时 f_mount 中的潜在错误。
  修复当 FF_FS_REENTRANT && FF_VOLUMES > 1 为真时文件锁控制 FF_FS_LOCK 不互斥的问题。
  修复当卷大小 >= 2^32 扇区时 f_mkfs() 创建损坏的 exFAT 卷的问题。
  修复当 FF_LFN_UNICODE == 2 (UTF-8) 时字符串函数无法写入不在 BMP 中的 Unicode 字符的问题。
  修复 GPT 标头识别中的兼容性问题。


R0.15a (2024年11月22日)
  修复 FF_FS_LOCK != 0 时的编译错误。
  修复 FF_FS_REENTRANT、FF_VOLUMES >= 2 和 FF_FS_LOCK > 0 并发工作时的潜在问题。
  使 f_setlabel() 在 FF_STR_VOLUME_ID == 2 时接受 Unix 风格卷 ID 中的卷标。
  使 FatFs 更新 exFAT VBR 中的 PercInUse 字段。(需要先调用 f_getfree() 以确保准确性)


R0.15b (2025年6月21日)
  添加创建时间戳支持。(FF_FS_CRTIME)
  修复 FatFs 无法加载 FAT32 卷中的 FsInfo 导致 f_getfree 始终强制完整 FAT 扫描的问题，这需要很长时间。(出现在 R0.15a)


R0.16 (2025年7月22日)
  移除长期存在的限制：exFAT 卷上的 f_getcwd 和路径名中的双点 .. 无法工作。
  修复 f_readdir 无法检测目录结束导致应用程序进入无限循环的问题。(出现在 R0.15b)
  修复未启用 LFN 时带有终止分隔符或重复分隔符的点名称被拒绝的问题。
